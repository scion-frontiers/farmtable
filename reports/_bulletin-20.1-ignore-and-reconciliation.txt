THE PATTERN IS dist/ WITH A TRAILING SLASH, WHICH MATCHES DIRECTORIES ONLY.
check-ignore does not consult a hypothetical; it consults the disk. So in a
pristine tree the honest answer to "is web/dist ignored" is exit 1, and that
answer is WRONG ABOUT WHAT HAPPENS WHEN YOU BUILD.

THE CLASS, and it is the project's central one in a new dress: AN INSTRUMENT
THAT IS ONLY AVAILABLE IN THE STATE WHERE ITS ANSWER DOES NOT MATTER, AND
UNAVAILABLE IN THE STATE WHERE IT DOES. The check can only be run truthfully
once the thing it warns about has already happened.
