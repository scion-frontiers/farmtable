## Method

All mutations were run through `/tmp/r10lab/mut.py`, a content-addressed harness that

- aborts unless `git status --porcelain` is empty **before** the mutation,
- aborts unless the anchor text occurs exactly the expected number of times,
- runs `npm test` as a **child process** and reads its **exit code** (never a pipe),
- scans the child's combined output for `error TS` and classifies such a run
  **TSC-FAIL**, not evidence,
- restores the original bytes in a `finally` and asserts the tree is clean after.

Predictions were made before each run and both prediction and result are recorded.
Where a control came back green, it is called out as a finding rather than dropped.

The last two are the ones that matter: M10+M2 and M10+M3 reconstruct the round-8
masking behaviour with the suite green at the round-9 pin.

**MUST 1b — two of the five rationales were measurably false.** The in-tree reason
given for reading the raw text at two sites was that blinding "would treat a trailing
template as empty". Measured:

```
literalBlindView('renderMarkdown(x) `junk`')  ->  'renderMarkdown(x) `    `'
```

`literalBlindView` blanks literal **contents** and keeps the **delimiters**. Quote
characters and backticks survive; `.trim()` is non-empty; the blinded read rejects
exactly what the raw read rejects. The same holds for a trailing string and for a
trailing identifier or operator, which are not literals at all.

**The one construct that blinds to pure whitespace is a comment**, because
`stripInertText` blanks comments wholesale with no surviving delimiter. So the honest
statement of what those two arms buy is narrower and it is now the one in the tree:
reading the blinded view would accept `renderMarkdown(x) /* c */`, and **no production
path can deliver that shape**, because every caller runs `callArguments` over an
already-comment-stripped view. The arms are defence in depth against a future caller
that stops pre-stripping. Both rationales were rewritten to say that.

**Fix.** `check('fixture: every structural scanner reports from the original, not the
blinded view')` — a size-pinned table of three scanners, each asserted to return a
slice still containing a literal that blinding would have blanked, plus four direct
assertions on `sinkArgumentIsSanitized` (two that must reject, two false-positive
mirrors). A provenance assertion was also added inside the `DYNAMIC_IMPORT_EVASIONS`
loop: every offender must quote a specifier that is actually present in the source.

**After, all nine RED**, with these failing check names:

| id | failing check(s) |
|---|---|
| M2 | the arity pin + `fixture: every structural scanner reports from the original, not the blinded view` |
| M3 | the arity pin only |
| M8, M9, M10, M11 | `fixture: every structural scanner reports from the original, not the blinded view` |
| M12 | the same, + `fixture: the dynamic-import specifier rule catches every unresolvable form` |
| M10+M2, M10+M3 | `fixture: every structural scanner reports from the original, not the blinded view` |
