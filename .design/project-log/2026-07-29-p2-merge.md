## Read the stage channel, not the prose channel

`git merge-tree --write-tree` emits two different things. Stage-numbered index
entries (`mode oid stage<TAB>path`) are the conflicts. Informational prose
includes `Auto-merging PATH`, **which git prints for files it merged
SUCCESSFULLY**.

At this base the prose channel lists 8 paths and the stage channel lists 7. The
difference is exactly `web/src/components/ft-app.ts`, which auto-merged cleanly.
Harvesting the prose is how the set was previously published as 8.

The predicate that gets it right:

```
git merge-tree --write-tree <base> <branch> > out
awk '$3 ~ /^[123]$/ {print $4}' out | sort -u
```

This was confirmed against the real index afterwards: `git diff --diff-filter=U`
returned the identical 7 paths.

## Stage composition is itself a finding

Five conflicted paths carry stages 1, 2 and 3. The two `safe-url` paths carry
**stages 2 and 3 only — no stage 1**. They are add/add: no merge-base version,
both sides wrote them from nothing. A three-way resolution is unavailable on
them, and the usual procedure quietly degrades into a pick-a-side. That is why
they are deferred rather than resolved.

## Known failing tests — confined to the deferred carve-out

`vitest run`: 30 tests fail across exactly 3 of 22 files, all branch-authored
safe-url dependents.

- `web/test/safe-url.contract.test.ts`
- `web/test/ft-inspector-code.safe-url.test.ts`
- `web/test/ft-inspector-meta.safe-url.test.ts`

Two genuine policy disagreements sit underneath, and both belong to the
adjudication:

1. On an unsafe URL, main renders degraded visible text (echoing the raw URL in a
   `title` attribute); the branch renders nothing.
2. On a remote `http:` URL, main links; the branch links only localhost, gated by
   `LOCAL_HTTP_LINKS_ENABLED`.

**No XSS regression.** Every "renders no href" assertion passes. The residual
`javascript:`/`data:` string matches are that raw URL sitting inertly inside a
`title` attribute, never in an `href`.

This is the one acceptance criterion this merge cannot meet, and it cannot be met
without choosing a side on `safe-url.ts`.
