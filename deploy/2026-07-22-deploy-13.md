Key fix in this deploy:
- **Feature 42** (PR #114): Restores `flex: 1` on the `.cards` CSS rule in
  `ft-kanban-column.ts`. PR #111 (Feature 39, single scroll region fix) had
  removed `flex: 1` along with `overflow-y: auto`, incorrectly assuming it was
  no longer needed. Without `flex: 1`, the `.cards` drop-target div shrunk to
  its content height instead of filling the column, creating massive dead zones
  (up to 95% of column area for empty columns) where real user drags silently
  failed. This is a 1-line CSS fix — `overflow-y: auto` correctly stays removed
  since `.main` now handles scrolling.

## Feature 42 Verification — DnD Dead Zone Fix (Playwright)

All verification performed with Playwright (Chromium headless, 1440x900 viewport) against the live
deployed URL `https://farmtable-486315127503.us-central1.run.app`.

**Methodology**: Used Playwright's `locator.dragTo()` which fires REAL HTML5 DnD events
(`dragstart`, `dragenter`, `dragover`, `drop`, `dragend`) — NOT mouse-based simulation. This is
critical because a prior investigation got a false negative using `mouse.move()` sequences, which
happened to land precisely on a card rather than the dead-zone area.

| Triage     | 0     | 1884px      | 1835px        | **0px**   | 1        |
| Backlog    | 0     | 1884px      | 1835px        | **0px**   | 1        |
| Ready      | 17    | 1884px      | 1835px        | **0px**   | 1        |

All columns now show `flexGrow: 1` and **0px dead zone**. Compare to the pre-fix state where
empty columns had ~1795px dead zones (95% of column area).

### V2 — Real HTML5 DnD Drop Into Previously-Dead Space — **PASS**

- **Source**: Ready column (17 cards), first card "Ready-09"
- **Target**: Triage column (0 cards, empty)
- **Drop position**: 1413px from column top (75% of 1884px column height)
- **Context**: Without `flex:1`, the Triage `.cards` div would have been only ~40px tall
  (from `min-height: 2rem`). This drop at 1413px was 100% dead space — 1373px below the
  old `.cards` bottom edge.
- **Method**: `sourceColLocator.dragTo(targetColLocator, { sourcePosition, targetPosition })`
  — real HTML5 DnD events
- **Result**: Card "Ready-09" successfully moved to Triage.
  - Ready: 17 → 16 cards
  - Triage: 0 → 1 card
- **Screenshot proof**: `06-board-post-dnd-scrolled-top.png` shows "Ready-09" card in Triage
  column with count badge showing "1", Ready column count badge showing "16".
