Key change in this deploy:
- **Feature 45: Beads JSONL Import** (PR #122):
  Adds import support for Beads' JSONL issue export format alongside Farmtable's
  native JSON export. The import dialog now states "Supported formats: Farmtable
  export (.json), Beads issue export (.jsonl)". Auto-detection chooses the
  correct parser based on file extension (`.jsonl` → Beads, `.json` → Farmtable
  with JSONL fallback). Beads issues are converted to Farmtable tasks with
  appropriate title, description, status, and priority mapping.
