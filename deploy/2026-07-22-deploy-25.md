Key change in this deploy:
- **Feature 51: Dependency View Layer-0 Alignment + Edge Anchoring** (PR #128):
  - Replaced dagre-driven layout in `ft-dependency-view` with manual layout
    using `computeLayers()` for correct layer-0 alignment.
  - Bug 1 fixed: Dagre's simplex ranking algorithm ignored per-node rank hints,
    shifting unblocked tasks away from layer 0 to minimize edge lengths.
    Now all layer-0 nodes render at identical X position (leftmost column).
  - Bug 2 fixed: Dagre computed edge paths using node center points as anchors.
    Now edges always emit from the RIGHT edge of the source node and attach to
    the LEFT edge of the target node using cubic bezier curves, preventing
    lines from routing through/under task boxes.
  - Layout: X = MARGIN + layer * (NODE_WIDTH + LAYER_GAP), strict column alignment.
  - dagre import removed from this component (npm dep retained for others).
  - All DnD, pan/zoom, centering functionality preserved.
