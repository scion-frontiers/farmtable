Key change in this deploy:
- **Feature 54: Minimap with Draggable Viewport Frame** (PR #131):
  - Added a shared `<ft-minimap>` web component (180x180px, bottom-left corner)
    to both the Tree view and Dependency view.
  - Renders a scaled-down overview of all graph nodes with edges.
  - Includes a draggable viewport frame indicator (semi-transparent indigo
    rectangle) that shows which region of the graph the main canvas is
    currently displaying.
  - Dragging the frame dispatches `minimap-pan` events, causing the main
    canvas to pan to the corresponding region.
  - Clicking anywhere on the minimap (outside the frame) centers the
    viewport on the clicked point.
  - Mouse wheel events on the minimap are forwarded to the parent view
    for zoom support.
