Key changes in this deploy:

1. **Perf Phase 2 — Dependency View Viewport Culling (PR #155)**: DOM is now only
   created for nodes/edges intersecting the current viewport (with a 220px margin to
   prevent pop-in), cutting DOM element count by ~95-99% on large collections. A
   `willUpdate()` guard also skips re-running layout/structureKey computation on
   pan/zoom-only changes, fixing janky panning on large graphs.

   Implementation details:
   - Viewport culling in `render()` filters `layoutNodes` to `visibleNodes` based on
     AABB intersection with the current viewBox plus margin.
   - Edges are rendered if at least one endpoint is in the visible set.
   - `PAN_ZOOM_KEYS` set in `willUpdate()` skips `runLayout()` + `structureKey()`
     when only pan/zoom state changed.
   - Minimap receives `this.layoutNodes` (ALL nodes), NOT the culled subset, so it
     always shows the complete graph overview.
   - Solo mode composes correctly — layout filtering happens before viewport culling.
   - DnD FLIP animation (Feature 64) unchanged and working.
