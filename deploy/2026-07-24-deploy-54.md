   "External Source" row in the Inspector's General tab. When a task has `remoteUrl` set
   (e.g. GitHub-sourced tasks), it shows a styled link with an external-link icon that

   Implementation in `ft-inspector-meta.ts`.

   rendering the tractor emoji (🚜), wired up via `<link rel="icon" type="image/svg+xml">`
   in `web/index.html`.
