  `7cd046b`, `5b05b01`):
  - New scope vocabulary: `task:read`, `task:write`, `task:claim`, `collection:read`,
    `collection:write`, `collection:admin`, `token:manage`, `user:read`, `*` wildcard.
  - `RequireScope()` enforced on all 28+ RPC handlers for scope-based access control.
  - `RequireCollectionAccess()` enforced on all RPC handlers for collection-level
    restriction.
  - `Scopes` and `CollectionIDs` fields added to the `ApiToken` schema (JSONB columns).
  - `ft token create --scope`/`--collection` CLI flags for creating scoped tokens.
  - Default scopes assigned by user type: admin=`*`, agent=task rw+claim+collection read,
    viewer=read-only, human/service_account=`*`.
  - **Backward compatibility**: nil/empty scopes treated as wildcard — existing tokens
    continue to work without migration.
- **Decomposer IAP flag** (commit `f44fa79`): `--iap-audience` flag for IAP-protected
  instances.
