Key change in this deploy:
- **Feature 52: Command Palette Search Scoping** (PR #130):
  - Command palette search now scoped to **title + labels only** (previously
    searched description, type, stage, assignees, and ID as well).
  - Search is case-insensitive using `fuzzyScore()` which lowercases both
    pattern and target before matching.
  - Fuzzy matching implemented: every character in the query must appear in
    order within the target, with scoring bonuses for consecutive matches and
    word-boundary matches.
  - Fixed a latent bug that silently dropped valid matches when the old broader
    search produced false negatives.
  - `searchableText()` now returns `[task.name, ...task.labels].join(' ')`.
