### Verification Summary

The Feature 49 fix adds two synchronization mechanisms:
1. **Client-side (optimistic):** `applyTaskUpdate()` in `ft-app.ts` now upserts
   reciprocal relationships on target tasks in the TaskStore immediately after
   mutating the source task, so the UI reflects them without a server round-trip.
2. **Server-side (event bus):** After publishing the TaskEvent for the mutated
   task, the server refetches and publishes events for each relationship target
   task so other connected clients see the reciprocal without waiting for the poll.

Both mechanisms were confirmed working: the client-side optimistic update was
verified by checking the store state before navigating to Task B, and the DOM
rendering was verified by inspecting the Relationships panel.
