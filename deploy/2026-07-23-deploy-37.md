Key changes in this deploy:
- **Post-hoc review fixes for Stage 5/6 wiring** (commit `5c05b0d`):
  1. **Startup validation**: Reject proxy mode when `FARMTABLE_IAP_AUDIENCE` is
     empty (prevents audience binding bypass); warn when OAuth mode lacks
     `FARMTABLE_GOOGLE_CLIENT_ID`.
  2. **Session-to-gRPC bridge**: Add `CreateSessionToken` to `UserProvisioner` and
     wire it into both OAuth callback and IAP middleware so `sessKeyToken` is set in
     the session. Enables `SessionToBearerMiddleware` to inject Bearer headers for
     gRPC requests in OAuth/IAP modes.
  3. **Encryption key validation**: Fail startup with `log.Fatalf` when
     `FARMTABLE_ENCRYPTION_KEY` is set but malformed, preventing silent fallback to
     plaintext credential storage.

Files changed: `cmd/farmtable-server/main.go`, `internal/serverapp/oauth.go`,
`internal/serverapp/provisioning.go`, `internal/serverapp/unified.go` (54 lines added).

**IMPORTANT**: `FARMTABLE_AUTH_MODE` was NOT set — deploy uses default `token` mode.
OAuth/proxy modes are NOT enabled. All changes are to opt-in code paths that are
inactive in this configuration.
