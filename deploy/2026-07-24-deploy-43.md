Key changes in this deploy (Feature 64, PR #147):
1. **FLIP node animation**: When a DnD creates a new BLOCKS relationship, the
   drop-target (blocking) node stays fixed while the dragged (blocked) node
   animates to its new layout position (~500ms FLIP transition).
2. **Progressive edge draw-in**: The new edge draws in via a stroke-dasharray
   reveal (~300ms) rather than appearing instantly.
3. **No full-graph rescale**: The viewport is adjusted so the blocking node stays
   visually fixed — eliminates the old full-rescale/zoom-out behavior that made
   the graph jump on every DnD drop.

Files changed: `web/src/components/dependency/ft-dependency-view.ts`.
