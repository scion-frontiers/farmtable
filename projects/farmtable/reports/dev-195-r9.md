### The fix

One shared helper, used by all five counters:

```ts
const literalBlindView = (code: string) =>
  stripInertText(code, { strings: true, templateText: true });
```

`stripInertText` gained a `templateText` option that blanks template **text**
only and preserves `${…}` interpolations, because that is where the sinks live.
The five call sites are `balancedDeclarationParameterLists`,
`splitTopLevelParameters`, `hasTopLevelDefault`, `callArguments` and
`sinkArgumentIsSanitized`. Structural decisions read the blinded view; slices and
messages read the original text.

`renderMarkdownArityViolation` **no longer pre-blinds its input**. See the
finding below — that was the difference between a class fix and a class-shaped
fix.
