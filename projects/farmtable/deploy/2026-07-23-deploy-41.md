65deb12 feat(routing): add task-level deep-linking via ?task= URL param (#145)

Key changes in this deploy (Feature 62, PR #145):
1. **Task deep-linking**: Loading a URL with `?task=<taskId>` selects the task,
   centers/zooms the Tree or Dependency view on it, and opens the Inspector.
2. **URL sync on selection**: Manually selecting a task or opening the Inspector
   updates the URL with `?task=<taskId>` (shareable).
3. **URL cleanup on deselect**: Closing the Inspector removes the `?task=` param.
4. **Collection switch cleanup**: Switching collections clears any stale `?task=`
   param from the URL.
5. **Kanban limitation**: Kanban View updates the URL with `?task=` but doesn't
   scroll-to-card (documented limitation, not a bug).

Files changed: `web/src/components/ft-app.ts` and related routing logic.

**LOW-RISK DEPLOY** — UI-only routing change, reviewed, with real verified
evidence from both local testing (PR #145) and this live deployment verification.
