Key change in this deploy:
- **Passthrough Write-Through Phase 3: Write Error Toasts + Type/Label Mapping** (PR #119):
  The final phase of the GitHub Passthrough Write-Through project. Adds:
  - **Write-error toasts**: When a GitHub write fails, a user-friendly Shoelace
    `sl-alert` toast (variant `danger`, 8s auto-close, closable) appears with a
    mapped message instead of a raw error dump:
    - Permission denied / 403 / Forbidden → "GitHub rejected this edit — your
      token may not have write access"
    - Rate limit / 429 / Too Many Requests → "GitHub rate limit reached — please
      wait before making more edits"
    - Network / fetch / ECONNREFUSED / unavailable / deadline → "Could not reach
      the server — your change will retry on the next sync"
    - Generic → "Failed to save changes: \<raw error\>"
  - **Task-type label mapping**: `TypeToLabel()` / `TypeLabelSwap()` methods
    enable write-through of task type changes to GitHub labels.
  - **Generic AddLabels/RemoveLabels handling**: Passthrough store now handles
    arbitrary label add/remove operations via GitHub GraphQL mutations.
