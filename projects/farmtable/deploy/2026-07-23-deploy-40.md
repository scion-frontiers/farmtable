Key changes in this deploy (Feature 61 v2, PR #144):
1. **Bug fix**: un-soloing (toggling Solo off) in Tree View now correctly returns
   to the full tree. Previously a redundant `lastStructureKey` clearing call was
   interfering with the layout recomputation on isolate-mode change.
2. **Dependency View Solo mode**: same Solo toggle concept as Tree View, but with
   bidirectional traversal — shows the selected node's full connected component
   via BLOCKS/BLOCKED_BY edges in both directions (not just descendants).
3. **Edge color-coding**: when a node is selected in Dependency View, edges to
   upstream blockers render red-orange (`#D55E00`, vermillion, Okabe-Ito palette),
   edges to downstream blocked-by tasks render blue-purple (`#7B3FF2`, custom
   colorblind-accessible). Edge color cache invalidates on poll/SSE-driven
   relationship changes (via composite cache key including `lastStructureKey`),
   not just on selection changes.

Files changed: `web/src/components/tree/ft-tree-view.ts`,
`web/src/components/tree/ft-hierarchy-nav.ts`,
`web/src/components/dependency/ft-dependency-view.ts`.

**LOW-RISK DEPLOY** — UI-only changes (Tree View + Dependency View components),
two review rounds passed, all findings addressed. No backend/auth/infra changes.
