Key change in this deploy:
- **Passthrough Write-Through Phase 2: Capability-Based UI Gating** (PR #118):
  GitHub-backed writable collections now show unmappable operations (dates,
  acceptance criteria, blocks/blocked-by, code context, delete, drag-reorder)
  as disabled with explanatory tooltips, while mapped operations (title,
  description, stage, priority, assignee, comments, create, close, reparent)
  remain fully functional. Farmtable-platform collections are unaffected
  (ALL_ENABLED). The implementation introduces a `CollectionCapabilities`
  interface with three presets: `ALL_ENABLED`, `GITHUB_CAPABILITIES`, and
  `ALL_DISABLED`, plus a `CAPABILITY_TOOLTIPS` map for user-facing explanations.
  The `getCapabilities()` function derives capabilities from `collection.platform`
  and `remoteData.writable`.
