Key change in this deploy:
- **Feature 44: Dependency Tree View** (PR #117): A new "Dependencies" view
  showing only BLOCKS/BLOCKED_BY relationships as a left-to-right layered DAG.
  Layer 0 (leftmost) contains unblocked/ready tasks; Layer N = 1 + max(blocker
  layers). Uses dagre for automatic graph layout. The view-switcher icon reuses
  the Tree view's `diagram-3` icon rotated 90° clockwise
  (`transform: rotate(90deg)`). CLOSED tasks are excluded from the view.
