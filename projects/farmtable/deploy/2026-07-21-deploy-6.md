### 1. Icon-Based View Switcher

The toolbar contains an `sl-radio-group.view-switcher` with 4 icon radio
buttons:

| Value | Aria Label | Icon |
|-------|-----------|------|
| `kanban` | Kanban view | Board columns |
| `tree` | Tree view | Tree/hierarchy |
| `ready-queue` | Ready Queue | List |
| `dashboard` | Dashboard view | Bar chart |

Clicking each button switches the view instantly. The active button is
highlighted in blue. **Screenshot:** `03-view-switcher-visible.png`

### 2. Command Palette (Ctrl+K)

Pressing `Ctrl+K` opens an `ft-command-palette` overlay with:
- A search input ("Search tasks…")
- Keyboard hint footer (↑↓ navigate, ↵ open, esc close)
- Live filtering — typing "dash" shows "No matching tasks" (correct: no
  tasks named "dash")

**Screenshots:** `06-command-palette-open.png`, `07-command-palette-search.png`

### 3. Dashboard View

Clicking the dashboard icon in the view switcher shows the
`ft-dashboard-view` component with:

- **Tasks by Phase:** Open (3), In Progress (1), On Hold (0), Closed (0), Total (4)
- **Tasks by Priority:** Urgent (0), High (0), Normal (1), Low (0), No priority (3)

**Screenshot:** `04-dashboard-view.png`

### 4. Ready Queue View (bonus)

The ready-queue view lists all 4 tasks with priority badges, truncated IDs,
and phase labels. **Screenshot:** `05-ready-queue-view.png`
