## What Phase C Would Need

A future server-side GitHub sync feature needs to add the missing server wiring, not just collection metadata:

1. Add a server-owned GitHub credential path: linked account/PAT/GitHub App installation storage and runtime token resolution for a collection.
2. Instantiate the GitHub adapter on the server for `platform=github` collections using `remote_id` owner/repo parsing.
3. Add an explicit `SyncCollection` RPC or background job trigger, with idempotent upsert behavior using `remote_id` and `remote_data`.
4. Return platform connection/sync status through `Status` or a dedicated endpoint so failures are visible instead of silent.
5. Decide when sync runs: on-demand CLI/dashboard button, scheduled background sync, webhook-driven sync, or a combination.
6. Expose CLI and/or dashboard controls for creating external collections and triggering/observing sync; the current CLI create path remains built-in-only.
