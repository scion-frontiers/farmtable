Key change in this deploy:
- **Phase 1 GitHub Passthrough Write-Through** (PR #116): Writes to GitHub-backed
  collections marked `remote_data.writable=true` now flow through to the real GitHub
  issue (title, description, comments). Features include optimistic UI updates, a
  15s poll-based reconciliation for writable collections, dirty-task guard with
  reference-counted tracking, and a "↔ GitHub" badge in the toolbar for writable
  external collections. The `isReadOnly` getter checks `remote_data.writable` per
  collection to unlock editing in the UI.
