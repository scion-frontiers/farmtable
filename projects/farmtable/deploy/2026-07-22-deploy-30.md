Key change in this deploy:
- **Feature 56: Zoom-to-Target-Size on Selection + Prominent Highlight Halo** (PR #133):
  - When a task node is selected in the Tree or Dependency view, the viewport
    now animates both pan AND zoom so the node's rendered width occupies ~20%
    of the container width (`targetScale = 0.20 * containerWidth / NODE_WIDTH`,
    clamped 0.3–3.0).
  - Scale and pan interpolate together each frame using the existing 750ms
    ease-in-out, keeping the node centered at every intermediate zoom level.
  - The selected-node highlight is more prominent: border widened to 3px
    (left accent 5px), and a two-layer box-shadow creates a halo ring with
    a visible gap (`0 0 0 3px transparent, 0 0 0 6px rgba(99,102,241,0.45)`).
  - `foreignObject` overflow set to `"visible"` for selected nodes to prevent
    SVG clipping of the halo.

narrower, so the node's fraction of the full viewport (13.5%) is smaller,
but the node correctly occupies 20% of the area the view actually controls.
