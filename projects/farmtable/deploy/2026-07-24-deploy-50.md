Key changes in this deploy:

1. **Feature 67 Tweak — LR Default + No Rotate-Button Highlight (PR #157)**: The Tree
   View's default layout orientation is now LR (left-to-right), changed from TB

   styling is untouched and still works.

   Implementation details:
   - `DEFAULT_LAYOUT_ORIENTATION` constant set to `'LR'` in `ft-app.ts`.
   - Default `layoutOrientation` changed from `'TB'` to `'LR'` in `ft-app.ts`,
     `ft-tree-view.ts`, and `ft-hierarchy-nav.ts`.
   - URL sync logic made generic: compares against `DEFAULT_LAYOUT_ORIENTATION` constant
     rather than hardcoding `'LR'`/`'TB'` checks.
   - `.active` class removed from the orientation toggle button template in
     `ft-hierarchy-nav.ts`; Solo button `.active` class logic unchanged.
